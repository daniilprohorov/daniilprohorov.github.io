# 02: Мост COM-порта и белый список

**What to build:** Страница `/` слушает последовательный порт гостя и по строке ровно `OPEN:<id>` с известным **ID приложения** переводит вкладку на маршрут из **белого списка** (`bike-geometry → /bikeGeometry/`). Всё остальное игнорируется.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Отправка `OPEN:bike-geometry` в ttyS0 гостя переводит вкладку на `/bikeGeometry/`, приложение отрисовывается
- [ ] `OPEN:` с неизвестным ID — вкладка остаётся на `/`
- [ ] `OPEN:` с произвольным URL — вкладка остаётся на `/`
- [ ] Вывод ядра и мусор с порта не вызывают переходов
- [ ] Браузерный тест покрывает позитивный и негативный сценарии (таймауты с запасом)
