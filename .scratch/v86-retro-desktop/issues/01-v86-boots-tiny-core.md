# 01: Голый v86 загружает Tiny Core на `/`

**What to build:** `/` загружает в браузере через v86 32-битный Tiny Core Linux до консоли; v86, BIOS и образ лежат в репозитории как статические ресурсы. Прежний список ссылок на **веб-приложения** остаётся на `/` внутри `<noscript>`. `/bikeGeometry/` не меняется и открывается без v86.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Открытие `/` с локального статического сервера показывает загрузку Linux до консоли
- [ ] Во время загрузки нет сетевой загрузки пакетов
- [ ] `/` без JavaScript показывает список ссылок, включая Bike Geometry
- [ ] Прямое открытие `/bikeGeometry/` работает без v86, приложение не изменено
- [ ] Общий размер загружаемых файлов `/` (образ + v86) записан в отчёт
