# Spec: Ретро-Linux рабочий стол с Bike Geometry

Status: ready-for-agent

## Problem Statement

Главная страница сайта — голый список ссылок. Хочу, чтобы посетитель попадал на живой ретро-Linux **рабочий стол** и запускал оттуда **веб-приложения** сайта, начиная с **Bike Geometry**, как будто это программа на старом Unix-десктопе. При этом прямая ссылка на Bike Geometry должна по-прежнему открывать приложение сразу, без загрузки Linux.

## Solution

`/` загружает в браузере через v86 настоящий 32-битный Tiny Core Linux с X11 и стандартным IceWM. В меню IceWM и на панели задач есть пункт **Bike Geometry**. Нажатие на него переводит текущую вкладку на `/bikeGeometry/`. Гостевая ОС передаёт браузеру только **ID приложения** (`bike-geometry`) через последовательный порт. Маршрут берётся из **белого списка** на стороне JavaScript. Возврат на рабочий стол — кнопкой «Назад» браузера; Linux при этом загружается заново. Без JavaScript на `/` показывается прежний список ссылок.

## User Stories

1. Как посетитель, я хочу при открытии `/` видеть загружающийся ретро-Linux рабочий стол, чтобы сайт ощущался как старый Unix-компьютер.
2. Как посетитель, я хочу видеть стандартный IceWM с меню и панелью задач, чтобы сразу понять, как пользоваться рабочим столом.
3. Как посетитель, я хочу найти пункт «Bike Geometry» в меню IceWM, чтобы запустить приложение привычным способом.
4. Как посетитель, я хочу кнопку «Bike Geometry» на панели задач, чтобы запускать приложение в один клик.
5. Как посетитель, я хочу, чтобы нажатие на Bike Geometry открывало `/bikeGeometry/` в той же вкладке, чтобы работать с полноценным приложением.
6. Как посетитель, я хочу вернуться на рабочий стол кнопкой «Назад» браузера, чтобы не искать отдельную ссылку.
7. Как посетитель, я понимаю, что после возврата Linux загружается заново, и это не ломает работу рабочего стола.
8. Как посетитель с прямой ссылкой на `/bikeGeometry/`, я хочу сразу видеть приложение без загрузки Linux, чтобы не ждать эмулятор.
9. Как посетитель без JavaScript (или поисковый робот), я хочу видеть на `/` список ссылок на веб-приложения, чтобы добраться до Bike Geometry.
10. Как посетитель, я хочу видеть в меню только работающие приложения, чтобы не натыкаться на заглушки.
11. Как посетитель, я хочу при желании открыть терминал внутри Linux, чтобы поиграться с настоящей системой.
12. Как посетитель на медленном интернете, я хочу, чтобы рабочий стол не требовал скачивания сотен мегабайт, чтобы он загрузился за разумное время.
13. Как посетитель, я хочу, чтобы рабочий стол работал без сетевой загрузки пакетов во время запуска, чтобы он был предсказуемым и офлайн-самодостаточным.
14. Как владелец сайта, я хочу, чтобы гостевая ОС не могла отправить браузер на произвольный URL, чтобы содержимое эмулятора не стало вектором открытого редиректа.
15. Как владелец сайта, я хочу, чтобы неизвестный ID приложения игнорировался, чтобы мусор с COM-порта не вызывал переходов.
16. Как владелец сайта, я хочу, чтобы Bike Geometry не знал о рабочем столе и не требовал пересборки, чтобы приложение оставалось самостоятельным.
17. Как владелец сайта, я хочу добавить новое веб-приложение, дописав запись в белый список и пункт меню, чтобы расширение было простым.
18. Как владелец сайта, я хочу, чтобы маршрут `/bikeGeometry/` не менялся, чтобы старые ссылки продолжали работать.
19. Как владелец сайта, я хочу знать итоговый размер образа и файлов v86, чтобы контролировать вес сайта.
20. Как владелец сайта, я хочу, чтобы сайт оставался статическим и разворачивался на GitHub Pages без сервера.

## Implementation Decisions

- **Хостинг**: статический сайт на GitHub Pages; без сервера и сборочного конвейера для самого сайта. Файлы v86 (эмулятор, BIOS) и образ Tiny Core кладутся в репозиторий как статические ресурсы.
- **Гостевая ОС**: 32-битный Tiny Core Linux x86, X11 + стандартный IceWM без тем. Все нужные пакеты вшиты в образ; загрузки расширений при старте нет.
- **Запуск без иконок на рабочем столе**: только меню IceWM и кнопка панели задач (toolbar IceWM). Пакеты вроде idesk не добавляются.
- **Гостевой скрипт `open-webapp <id>`**: пишет в `/dev/ttyS0` строку `OPEN:<id>` с переводом строки. Пункт меню и кнопка панели вызывают `open-webapp bike-geometry`, подпись «Bike Geometry».
- **Протокол COM-порта**: построчный текст; распознаётся только строка ровно вида `OPEN:<id>`. Остальное (вывод ядра, мусор) игнорируется.
- **Обработчик в странице `/`**: подписан на событие v86 `serial0-output-byte`, собирает байты в строки, ищет ID в белом списке и вызывает `window.location.assign(маршрут)`. Неизвестный ID — без действия.
- **Белый список** (единственный источник допустимых переходов): `bike-geometry → /bikeGeometry/`. ID приложения, маршрут и подпись — три отдельных имени (см. `CONTEXT.md`).
- **Главная страница**: текущий `index.html` заменяется рабочим столом; прежний список ссылок остаётся внутри `<noscript>`.
- **Bike Geometry не меняется**: ни ссылки «Назад на рабочий стол», ни пересборки.
- **Без iframe и HTML-окон поверх v86.** Полный переход уничтожает экземпляр v86; состояние не сохраняется.

## Testing Decisions

- Хороший тест проверяет внешнее поведение так, как его видит посетитель: что появляется на странице и куда уходит вкладка. Не проверяем внутренности обработчика, формат буфера или содержимое скриптов.
- **Один шов — браузер на `/`**: открыть `/` в реальном браузере с локального статического сервера, дождаться загрузки IceWM, запустить Bike Geometry (кликом в меню/панели или отправкой `OPEN:bike-geometry` через ttyS0 гостя) и проверить, что вкладка перешла на `/bikeGeometry/` и приложение отрисовалось.
- Негативный сценарий на том же шве: `OPEN:` с неизвестным ID или произвольным URL — вкладка остаётся на `/`.
- Отдельно на том же уровне: прямое открытие `/bikeGeometry/` работает без v86; `/` без JavaScript показывает список ссылок.
- Замер общего размера загружаемых файлов `/` (образ + v86) фиксируется в отчёте о выполнении.
- Прецедентов тестов в репозитории нет; модульные тесты белого списка не пишем.

## Out of Scope

- Пункты Files, Browser, Settings и любые заглушки.
- Иконки на рабочем столе, темы IceWM, стилизация под IRIX.
- Открытие приложений внутри Linux, iframe, HTML-окна поверх эмулятора.
- Сохранение состояния v86 между переходами.
- Ссылка «Назад на рабочий стол» внутри Bike Geometry; перенос приложения в `/apps/`.
- Фиксированный бюджет размера образа (замеряется после сборки).
