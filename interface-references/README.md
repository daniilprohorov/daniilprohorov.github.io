# Интерфейсы: настоящий стол, комната и предметы

Подборка для поиска визуального направления, а не коллекция обычных оконных desktop-интерфейсов. Отправная точка — [Sony Magic Link / Magic Cap](https://pikabu.ru/story/vzglyad_v_proshloe_sony_magic_link_pic1000_4292534).

В подборке оставлены два подходящих референса: **Magic Cap** и **Microsoft Bob**. Оба используют пространственный интерфейс: рабочий стол или комнату, где знакомые предметы представляют функции программы. Каждый референс лежит в отдельной папке с изображениями, пояснениями и ссылками на источники.

## Базовый референс

[Magic Cap](magic-cap/) — письменный стол с телефоном, бумагой, календарём, почтовыми лотками и ящиками. Сохранены монохромная иллюстрация из исходной статьи и два скриншота предварительной Windows-версии: стол и коридор. Версии подписаны отдельно, чтобы не принимать цветную Windows-версию за экран Sony Magic Link.

## Microsoft Bob

[Microsoft Bob](microsoft-bob/) — нарисованная комната с предметами вместо обычных ярлыков. Референс для комнатной метафоры: функции программы представлены как объекты в знакомом домашнем окружении.

## Как смотреть

- **Композиция:** видна ли вся рабочая поверхность, насколько легко найти нужный предмет.
- **Метафоры:** что можно выразить письмом, книгой, ящиком, прибором или дверью вместо кнопки.
- **Графика:** контур, дизеринг, ограниченная палитра, объём и материал предметов.
- **Навигация:** переходы между столом и комнатами; насколько легко найти нужную функцию.
