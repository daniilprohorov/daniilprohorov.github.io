# План: ретро-Linux-десктоп в браузере

## Что решили

- **v86** запускает настоящий **32-битный Tiny Core Linux** прямо на сайте.
- GUI — **X11 + IceWM**: лёгкий рабочий стол в стиле старых Unix/Linux. Для начала используем стандартный IceWM, без тем и сложной стилизации под IRIX.
- Внутри Linux работают рабочий стол, меню и при необходимости терминал.
- «Приложения» в меню IceWM на первом этапе **не открываются внутри Linux**: нажатие полностью перенаправляет текущую вкладку на соответствующий URL веб-приложения.
- Единственное приложение MVP — **Bike Geometry** (`/bikeGeometry/`, уже собрано). Пунктов-заглушек (Files, Browser, Settings) нет.
- Bike Geometry запускается из **меню IceWM и кнопки на панели задач**. Иконки на самом рабочем столе не делаем (потребовали бы idesk или аналог).
- `/` — рабочий стол v86. Прямая ссылка `/bikeGeometry/` открывает приложение сразу, без Linux. Текущий список ссылок остаётся в `<noscript>`.
- **Никаких iframe или HTML-окон поверх v86 пока не нужно.**
- Цель — компактный образ без скачивания сотен мегабайт. Конкретный размер выясним после сборки; отдельно учитываем файлы v86.

## Механизм запуска приложений

1. Пункт меню или кнопка на панели IceWM запускает `open-webapp bike-geometry`.
2. Скрипт отправляет в последовательный порт `/dev/ttyS0` строку `OPEN:bike-geometry`.
3. JavaScript слушает событие v86 `serial0-output-byte` и сопоставляет `bike-geometry` разрешённому маршруту `/bikeGeometry/`.
4. Браузер выполняет `window.location.assign('/bikeGeometry/')`.
5. Ссылки «Назад на рабочий стол» в приложении нет: возврат — кнопкой «Назад» браузера. Приложение о рабочем столе не знает.

Маршруты задаются **в JavaScript белым списком** — нельзя доверять произвольному URL из гостевой ОС.

## Первый прототип

1. Запустить Tiny Core x86 с X11/IceWM в v86.
2. Собрать минимальный образ с необходимыми пакетами и зависимостями, без загрузки пакетов при запуске.
3. Добавить `open-webapp`, пункт меню и кнопку панели `Bike Geometry`.
4. Реализовать обработчик COM-порта в JS и обычные переходы на страницы.
5. Проверить загрузку и размер всех файлов сайта.

**Ограничение:** полный переход со страницы уничтожает запущенный экземпляр v86; при возвращении на `/` Linux загружается заново. Сохранение состояния и встроенные HTML-окна — возможные улучшения позже, но не часть MVP.
