# Дизайн-концепция главной страницы

Главная (`index.html`) — личная домашняя страничка в стиле web 1.0 / GeoCities конца 90-х: весело, ностальгично, но читаемо. Ностальгия — через форму (рамки, бегущая строка, табличная раскладка), а не через нечитаемые цвета и мусорные декорации.

## Раскладка

Табличная вёрстка `<table class="main">` в три колонки:

| Левая колонка | Центр | Правая колонка |
|---|---|---|
| Круглые часы (МСК) | «✨ Мои проекты ✨» + мигающее NEW! | Погода в Питере |
| Календарь текущего месяца | Скриншоты приложений в рамке с подписью | Обо мне (ссылка на CV) |
| | | Счётчик посетителей |

Сверху вниз: бегущая строка `<marquee>` → заголовок `~ Daniil Prohorov ~` → полоса «🚧 UNDER CONSTRUCTION 🚧» → радужный `<hr>` → три колонки → радужный `<hr>` → подвал `© 2026` (с 2027 года — `© 2026–<текущий год>`, подставляется скриптом).

## Визуальный язык

- Фон страницы — белый.
- Шрифт — Comic Sans MS.
- Боковые блоки (`.box`) — тёмно-синие (`#000080`) с рамкой `ridge`, заголовки ярко-зелёные, текст белый.
- Заголовок страницы — синий, переливается в малиновый, розовая тень.
- Бегущая строка — белый текст на мадженте.
- Проект = скриншот в рамке `8px outset #c0c0c0` + подпись на фиолетовой плашке (эмодзи, ссылка, короткое описание). Клик по скриншоту и по ссылке ведёт в приложение.

## Правила

- **Никакого жёлтого (и другого светлого) текста на белом фоне** — нечитаемо. Жёлтый допустим только на тёмных подложках (внутри `.box`, на чёрной полосе UNDER CONSTRUCTION).
- Проверяй контраст текста после смены фона или цвета: текст, унаследованный от `body`, может слиться с фоном блока.
- **Без «шизовых» декоративных элементов**: никаких кнопок 88×31 (NETSCAPE NOW!, HTML 3.2 и т. п.), «Best viewed in…», фейковых гостевых книг и ссылок в никуда. Каждый элемент либо работает, либо является одной узнаваемой деталью стиля (marquee, UNDER CONSTRUCTION, радужный hr, счётчик).
- Подвал — только год разработки.

## Виджеты

Общий скрипт `assets/widgets.js`, подключается по data-атрибутам:

- `data-clock` — круглые SVG-часы, время по `Europe/Moscow`, обновляются каждую секунду; подпись `МСК ЧЧ:ММ`.
- `data-calendar` — сетка текущего месяца (по МСК), неделя с понедельника, выходные красные, сегодня выделено.
- `data-weather` — погода в Санкт-Петербурге (59.94, 30.31) из [Open-Meteo](https://open-meteo.com) (без ключа, CORS разрешён), обновление раз в 30 минут; при ошибке — «нет данных».
- `data-counter` — декоративный счётчик посетителей: число часов с 22.08.2025 (≈10 000 в октябре 2026), 7 цифр с ведущими нулями. Считается **один раз при загрузке**, пока пользователь на странице — не меняется.

Цвета виджетов задаются в `index.html` через классы (`.clock-face`, `.clock-s`, `.cal .today`, `.w-temp` и т. д.), сам скрипт стилей не содержит.
