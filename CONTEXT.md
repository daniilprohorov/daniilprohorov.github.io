# Context

## Glossary

- **Рабочий стол** — ретро-Linux (Tiny Core + twm) в v86 на `/`. Каталог веб-приложений сайта.
- **Веб-приложение** — самостоятельная страница сайта со своим маршрутом; работает и без рабочего стола по прямой ссылке. Не знает о рабочем столе.
- **ID приложения** — kebab-case имя в протоколе `OPEN:<id>` (например `bike-geometry`); отличается от маршрута и подписи.
- **Bike Geometry** — единственное веб-приложение MVP; ID `bike-geometry`, маршрут `/bikeGeometry/`.
- **Белый список** — сопоставление ID приложения → маршрут на стороне JavaScript; единственный источник допустимых переходов из гостевой ОС.
